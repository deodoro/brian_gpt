2.  Two types of agents consume guns (g) and butter (b).  The Type A agents 
have U=.5 g + .5 b.  The Type B agents have U=.3 g + .7 b.  All agents initially 
own 1 uni t of guns and 1 unit of butter.  50% of the agents are type A; 50% are 
type B.  
 
True, False, and Explain:  General equilibrium does not exist because the 
agents' demand functions are discontinuous  in price . 
 
FALSE.  Since these are linear utility functions,  they DO generate demand functions that are 
discontinuous in price.  (E.g., the Type A agents want only guns if p g<p b, and only butter if p b<p g).  
However, this continuity is not a necessary  condition for GE to exist (rather it is one item on a list 
of suf ficient conditions).  In fact, GE exists in this economy if p g=p b.  Then the type Bs sell all of 
their guns, and the type As are not unwilling to sell all of their butter.  In equilibrium, then, the Type 
As have all the guns and the Type Bs have all of the  butter.
